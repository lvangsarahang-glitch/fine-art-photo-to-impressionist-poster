# Fine Art Photo → Impressionist Poster

将真实旅行摄影照片转化为高端、克制的竖版艺术旅行海报。

## 核心视觉语言

- Minimal editorial poster
- Poetic city illustration
- Contemporary art book aesthetic
- Scandinavian minimalism
- Japanese editorial design
- Quiet luxury poster
- Refined print design
- Impressionist oil painting
- Soft gouache / dry-brush inspired painterly texture

## 默认尺寸

**2880 × 3840 px，竖版 3:4**

## 构图

采用上下双区域构图：

- 上半部分：约 50% 的真实摄影区域
- 下半部分：约 50% 的印象派艺术转译区域
- 中间：自然、柔和的摄影 → 油画渐隐过渡
- 顶部：保留更多自然天空/环境留白
- 下半部分：油画主体不铺满，保留大量浅色负空间

上下两个主要视觉区域保持约 **1:1**。

这里的 1:1 指视觉区域的比例关系，不是两张图片进行机械的水平硬切。

## 上半部分：真实摄影

以用户原始照片为唯一视觉依据。

尽可能保留：

- 原始摄影视角
- 原始构图
- 建筑比例
- 地标轮廓
- 天空与云层
- 山脉
- 城市建筑
- 水面
- 人物
- 船只
- 灯光
- 原始色彩关系

仅允许为了适应竖版构图进行等比例缩放、轻微裁切和重新取景。

不重新绘制，不插画化，不改变建筑结构，不增加原照片不存在的主体。

## 下半部分：印象派油画

根据原照片的：

- 空间关系
- 地标位置
- 建筑层次
- 天空结构
- 水面关系
- 色彩关系
- 光影关系

重新创作印象派油画。

不直接对照片添加油画滤镜。

建筑、远景和环境进行适度概括，以色块、碎片化笔触和松散轮廓表达。

## 油画笔触

油画必须具有真实、明显、可见的手工绘画质感。

重点使用：

- 短而松散的笔触
- 断裂笔触
- 干刷
- 湿画法
- 轻微厚涂
- 厚薄不均的颜料堆叠
- 印象派碎色
- 不规则颜料边缘
- 自然的色彩交叠
- 轻微画布或纸面质感

笔触参考用户提供的印象派油画参考图。

参考的是笔触语言、颜料质感和绘画方式，而不是复制参考图的具体构图或内容。

## 留白

下半部分不能铺满。

油画主体建议只占下半部分约 **50%–60%**。

四周保留大量：

- 象牙白
- 米白
- 暖灰白
- 极浅蓝灰

油画边缘应逐渐：

**笔触减少 → 颜色变淡 → 细节消失 → 融入浅色画布**

顶部摄影区域也应保留足够的天空与环境留白。

## 上下过渡

照片与油画之间必须自然连接。

推荐：

**真实照片 → 摄影逐渐淡化 → 油画笔触出现 → 油画逐渐完整 → 笔触逐渐稀疏 → 浅色画布**

禁止：

- 硬切
- 横向分割线
- 明显拼贴
- 矩形蒙版
- 装饰边框

## 色彩

下半部分颜色主要来源于原始照片。

保持原照片的主要色调关系，同时降低：

- 饱和度
- 对比度
- 色彩浓度

整体保持：

**柔和、低饱和、低对比、通透、安静。**

避免霓虹色、赛博朋克色彩和过度鲜艳的商业插画色彩。

## 标题

默认使用地点名称。

例如：

**VENICE**

**FLORENCE**

**PARIS**

标题采用：

- 高端衬线字体
- 细字重
- 小字号
- 略宽字距
- 水平居中
- 克制优雅

标题放在最下方留白区域。

除标题外不要增加其他文字。

## 禁止

不要满版构图、不要油画主体过大、不要高饱和、不要高对比、不要厚重现代油画、不要卡通、不要漫画、不要矢量插画、不要扁平 UI、不要数字渐变、不要黑色描边、不要 3D、不要赛博朋克、不要霓虹色、不要拼贴、不要明显上下分割线、不要装饰边框、不要水印、不要额外文字。

不要改变上半部分真实摄影，不要修改建筑结构，不要增加原照片不存在的主体。

## 核心目标

最终效果：

**真实摄影 + 印象派油画 + 大量负空间 + 自然渐隐 + 高级编辑设计**

整体应具有当代旅行摄影艺术书和高级艺术海报的视觉气质。
